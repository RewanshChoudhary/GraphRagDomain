# GraphRagDomain

GraphRagDomain contains the `graphrag-entertainment` Python application for
retrieval augmented generation over entertainment reviews.

```text
GraphRagDomain/
├── README.md, LICENSE, .gitignore   # repository-level information
└── graphrag-entertainment/          # application, data, database, and experiments
    ├── src/graphrag_entertainment/  # all application code
    ├── data/                        # source and processed datasets
    ├── db/                          # database schema and migrations
    ├── experiments/                 # standalone RAG experiments
    └── tests/                       # integration request examples
```

See [the project README](graphrag-entertainment/README.md) for component
details and setup instructions.
